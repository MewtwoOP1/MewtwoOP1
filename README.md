# Mewtwo — A Legendary Pokémon

A cinematic Japanese-landscape personal website built with Astro, CSS and vanilla JavaScript.

## Features
- Responsive cinematic landscape design
- Falling sakura petals
- Japanese-inspired typography and atmosphere
- Auto-changing quote system with API + offline fallback
- Discord profile button
- Static Astro build for GitHub Pages
- Reduced-motion accessibility support

## GitHub Pages
Set Pages source to **GitHub Actions**. The included workflow builds and deploys the `dist/` folder.

For `MewtwoOP1.github.io`, the Astro config already uses `/` as the base URL.
